# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [1.0.1] — 2026-07-27

### Исправлено

- При выключении плагина игрокам возвращается обычный ник: раньше в таб-листе
  навсегда оставалось последнее показанное значение пинга.
- Некорректное значение `ping-update-interval` (меньше 1) больше не приводит
  к неверной частоте обновления: плагин пишет предупреждение в лог и использует
  значение по умолчанию (20).

## [1.0.0] — 2024-09-16

Первый публичный релиз.

### Добавлено

- Отображение пинга каждого игрока в таб-листе.
- Цветовая индикация: зелёный (< 100 ms), жёлтый (100–199 ms), красный (≥ 200 ms).
- Настройка частоты обновления через `ping-update-interval` в `config.yml`.

### Поддержка

- Minecraft 1.21.x, Paper API 1.21.1, Java 21.
