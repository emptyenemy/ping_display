# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [1.0.0] — 2024-09-16

Первый публичный релиз.

### Добавлено

- Отображение пинга каждого игрока в таб-листе.
- Цветовая индикация: зелёный (< 100 ms), жёлтый (100–199 ms), красный (≥ 200 ms).
- Настройка частоты обновления через `ping-update-interval` в `config.yml`.

### Поддержка

- Minecraft 1.21.x, Paper API 1.21.1, Java 21.
