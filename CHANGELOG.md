# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [1.0.2] — 2026-07-27

### Добавлено

- Команда `/pingdisplay` (алиас `/pd`) с подкомандами:
  `/pingdisplay [игрок]` — посмотреть пинг в чате, `/pingdisplay on` и `off` —
  включить или выключить отображение без удаления плагина, `/pingdisplay reload` —
  перечитать конфиг без рестарта сервера, `/pingdisplay help` — список команд.
  Права: `pingdisplay.check` (по умолчанию у всех), `pingdisplay.toggle`
  и `pingdisplay.reload` (по умолчанию у операторов).
- Ник, совпадающий с названием подкоманды, доступен через `@`: `/pingdisplay @off`.
- Настраиваемые пороги окраски: `ping-threshold-good` и `ping-threshold-medium`.
- Настраиваемые цвета: `ping-color-good`, `ping-color-medium` и `ping-color-bad`.
  Принимают название цвета или hex-код вида `#55FF55`.
- Настраиваемое содержимое колонки: `ping-format` с плейсхолдером `%ping%`.
- Параметр `enabled` — состояние `on`/`off` переживает перезапуск сервера.
- Параметр `ping-update-threshold` — не обновлять таб-лист, пока пинг не изменится
  на заданное число миллисекунд.

### Изменено

- **Пинг больше не подменяет ник игрока.** Раньше плагин каждый тик перезаписывал имя
  в таб-листе целиком, конфликтуя с любым плагином, который тоже оформляет ники.
  Теперь значение выводится отдельной колонкой через scoreboard-объектив в слоте
  `PLAYER_LIST`, а имена остаются за сервером и другими плагинами.
- Плагин ориентирован на Minecraft 26.2, Paper API 26.2, Java 25.
- Задача обновления переведена с `BukkitRunnable` на `GlobalRegionScheduler`:
  работает и на Paper, и на Folia.
- Отображение переведено с устаревшего `setPlayerListName(String)` на Adventure
  `Component`.

### Исправлено

- Отрицательное значение `getPing()` (случается в первые тики после подключения)
  больше не показывается как отрицательный пинг.
- Таб-лист не обновляется, если пинг игрока не изменился.
- Записи об отключившихся игроках больше не накапливаются в памяти и в объективе.

## [1.0.1] — 2026-07-27

### Исправлено

- При выключении плагина игрокам возвращается обычный ник: раньше в таб-листе
  навсегда оставалось последнее показанное значение пинга.
- Некорректное значение `ping-update-interval` (меньше 1) больше не приводит
  к неверной частоте обновления: плагин пишет предупреждение в лог и использует
  значение по умолчанию (20).

## [1.0.0] — 2024-09-16

Первый публичный релиз.

### Добавлено

- Отображение пинга каждого игрока в таб-листе.
- Цветовая индикация: зелёный (< 100 ms), жёлтый (100–199 ms), красный (≥ 200 ms).
- Настройка частоты обновления через `ping-update-interval` в `config.yml`.

### Поддержка

- Minecraft 1.21.x, Paper API 1.21.1, Java 21.
